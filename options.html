How it works on claude.ai
1
Open claude.ai and start typing a prompt in the chat box
2
An Optimize button appears next to the Send button
3
Click it — Prompt Forge reads your prompt and the current conversation for context
4
It searches proven patterns from prompts.chat, GitHub, and built-in libraries, then calls Groq to rewrite yours as an AI-optimized XML prompt
5
The optimized prompt is placed back in the chat box — with XML tags, MUST/NEVER rules, and positive+negative examples
Popup (any site)
Click the Prompt Forge toolbar icon on any page to open the standalone popup. It searches prompts.chat, GitHub's awesome-chatgpt-prompts, and built-in proven patterns — no API key required for this mode.
